# Capstone Projects - Test Automation

Welcome to the **Test Automation Capstone Projects** repository. This repository includes four individual case studies demonstrating practical implementations of automation testing using various tools and technologies. Each case study is a hands-on project showcasing different aspects of automation testing.

---

## 📁 Capstone Project 1: Selenium with Java Concepts

### 🧪 Description:
This project is a detailed case study focusing on end-to-end web application testing using **Selenium WebDriver with Java**.

### 🔧 Technologies Used:
- Java
- Selenium WebDriver
- TestNG
- Maven
- Extent Reports

### 📌 Key Concepts:
- Browser automation
- TestNG framework structure
- Page Object Model (POM)
- Data-driven testing
- Screenshot capture on failure
- Reporting with Extent Reports
